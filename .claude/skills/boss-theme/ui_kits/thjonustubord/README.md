# Þjónustuborð — Boss

The reference screen: the service desk at 1440px in the Boss finish. Open
`Þjónustuborð boss v4.dc.html`. Every token in `../../tokens/` was measured from
this file; if the two ever disagree, the screen wins and the token is wrong.

What to look at:

- Header: gold band, medallion, `--gold-text` wordmark, breathing LCD clock
- Sidebar: `--gold-side` on the active item, gold-lined brushed footer plate
- Panels `01`–`05`: brushed strip, gold hairline, plate before the title, one gold button each
- `06 Valið mál`: the dark slab with gold-lined top rule and the large gold action
- Nýjast: gold `◆` pin marks the selected row
- Empty states: ghost medallion above the sentence

Data is the same twelve-case sample as the other desk kits; names are examples.
