# Lög um bókhald nr. 145/1994

- **Gildistaka:** 1. jan. 1995. Lesin útgáfa: 158a (1. okt. 2026).
- **Hlekkur:** https://www.althingi.is/lagas/nuna/1994145.html
- **Reglugerðir settar á grundvelli 42. gr.:** 600/1999, 505/2013, 696/2019, 1101/2021.

| Gr. | Efni |
|---|---|
| 1.–2. gr. | Ehf. eru bókhaldsskyld og eiga að halda tvíhliða bókhald. |
| 6.–7. gr. | Rekja þarf viðskipti og notkun fjármuna. Skrifleg lýsing á bókhaldskerfinu skal liggja fyrir. **Kerfið okkar (solur → Payday/dkPlus, kostnadur, Vasinn) er hluti af þeirri lýsingu.** |
| **8. gr.** | Hver færsla byggir á áreiðanlegum gögnum sem rekja má til viðskiptanna (fylgiskjal). |
| 9. gr. | Viðskipti skal skrá jafnskjótt og þau fara fram. |
| 15. gr. | Viðskiptamannabókhald: reikningur fyrir hvern viðskiptamann. |
| **16. gr.** | Vörubirgðir eru taldar og verðmetnar í lok hvers reikningsárs (heiti, magn, einingarverð). Þetta tengist `vorur.birgdir`. |
| **17. gr.** | Tekjuskráning byggir á öruggu kerfi: reikningar í **öruggu skipulegu númerakerfi** og sjóðvélar. |
| **19. gr.** | Fylgiskjöl eru tölusett og geymd í samfelldri töluröð. |
| **20. gr.** | Varðveisla í **7 ár** frá lokum reikningsárs, á Íslandi. Rafræn gögn skulu ætíð vera aðgengileg yfirvöldum. Ársreikning skal varðveita í **25 ár**. |
| 21. gr. | Ekki má eyða eða gera ólæsilegt það sem eitt sinn hefur verið fært. |
| 36.–38. gr. | Refsiákvæði. Meiri háttar brot eru m.a. að eyðileggja bókhald eða skjóta því undan. |
